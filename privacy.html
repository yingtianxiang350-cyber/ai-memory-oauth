Privacy Policy

AI-Memory-Sync · Last updated: October 21, 2026

AI-Memory-Sync is a personal application operated by its owner. It connects to the owner's Google Drive using OAuth and is intended for maintaining a private AI memory archive. It does not provide public user accounts.

Google data accessed

When authorized, this application can access Google Drive files and metadata, including document content, names, and folder organization. The requested full Google Drive scope allows reading, creating, modifying, and deleting files across the authorized account, even though normal synchronization is configured to focus on the owner's AI-Memory folder.

How data is used

Data is used to synchronize the owner's knowledge archive with an owner-controlled server and to build searchable local indexes. Optional memory-management functions may automatically update archive documents when enabled by the owner. No data is used by this application for advertising or sold to data brokers.

Storage and protection

Authorized files, local search indexes, synchronization logs, and backups may be stored on infrastructure controlled by the owner. OAuth credentials and tokens are stored in private configuration files on the owner's devices or server. The public website hosting this notice contains no Google Drive contents or authentication credentials.

Sharing and AI integrations

The application does not intentionally publish the owner's Google Drive data or share it with advertisers. Google processes authorization and Google Drive API requests; server and hosting providers process data needed to run the owner's infrastructure. If the owner separately connects an AI service to the archive, information sent to that service is subject to that provider's terms and privacy policy. This website itself has no analytics or advertising scripts.

Retention and deletion

Synced files and indexes remain under the owner's control until removed. Backups may retain historical versions until their configured retention period expires. The owner can remove local copies and revoke Google authorization through Google Account connections. Revoking access stops new authorized API access but does not automatically erase copies previously stored on the owner's server or backups.

Access and contact

Because this is an owner-only tool, the owner controls access, correction, and deletion. Questions about the OAuth application can be directed to the developer contact email configured on its Google OAuth consent screen.

Policy updates

This notice will be updated if the application begins using or sharing Google user data in materially different ways.
